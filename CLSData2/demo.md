## CPW Demo

This folder provides a demonstration of the CPW prediction workflow, including candidate molecules, target pathways, and the corresponding prediction results.

### File Description

- **`demo.csv`**: A demo dataset containing candidate molecules for CPW-based screening.
- **`pathways2predict.csv`**: A list of target pathways used to evaluate the candidate molecules.
- **`molecule_total_scores_with_pathway_scores.csv`**: The prediction results generated by CPW, including the overall scores of candidate molecules and their corresponding pathway-specific prediction scores.

### Usage

The files `demo.csv` and `pathways2predict.csv` serve as the inputs for the CPW prediction workflow. The resulting predictions are provided in `molecule_total_scores_with_pathway_scores.csv` for downstream analysis and candidate molecule prioritization.
